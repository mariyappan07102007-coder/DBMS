WEEK 3 – SELLER & INVENTORY MANAGEMENT SYSTEM
==================================================

FILES
-----
1. Week3_Seller_Inventory_Management.sql
   Complete MySQL 8.x database creation, constraints, sample data,
   CRUD operations, seller/product operations, inventory operations,
   and analysis/report queries.

2. Week3_Seller_Inventory_Documentation.docx
   Editable assignment documentation.

3. Week3_Seller_Inventory_Documentation.pdf
   PDF version of the documentation.

4. ER_Diagram.png
   Updated ER diagram for Seller, Product, Seller_Product and Inventory.

HOW TO RUN
----------
1. Open MySQL Workbench.
2. Open the .sql file.
3. Execute the entire script.
4. The database SellerInventoryDB will be created.
5. Run the report queries at the end to see the analysis.
6. Take screenshots of the result grids if required by your teacher.

IMPORTANT
---------
The script uses MySQL 8.x syntax.
Seller_Product is included because Seller <-> Product is naturally
a many-to-many relationship. Inventory links both Seller and Product.
